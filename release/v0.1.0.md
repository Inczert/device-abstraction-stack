# DAS v0.1.0

DAS v0.1.0 is the first tagged Device Abstraction Stack baseline for the STM32H755 on NUCLEO-H755ZI-Q.

It provides the C11/CMake foundation for Cortex-M startup/vector ownership, CM7/CM4 images, clock/power/time, GPIO/EXTI/IRQ, UART, SPI, I2C, timer/PWM, DMA/cache, semantic board resources and CM7 polling Layer-2 Ethernet. DMA handles are allocation-specific and reject stale stream references after release/reacquisition. Fatal Ethernet DMA faults and TX timeouts require explicit MAC/DMA reinitialization; ordinary cable-loss recovery does not.

## Package contents

Two target-specific prebuilt install archives are published:

- `das-0.1.0-stm32h755-cm7.tar.gz`
- `das-0.1.0-stm32h755-cm4.tar.gz`

For consumers that only need the archive itself, the release also attaches:

- `libdas-0.1.0-stm32h755-cm7.a`
- `libdas-0.1.0-stm32h755-cm4.a`

Each complete package contains `libdas.a`, public headers, CMake package metadata, the selected linker script, Apache-2.0 license, ABI/build metadata and release provenance. `SHA256SUMS` covers both package tarballs and standalone static libraries.

The source/tag remains authoritative. Consumers may also build DAS directly from the tagged source.

## Compatibility

DAS is pre-1.0. The 0.1 CMake package line intentionally uses same-minor compatibility. Future 0.x minor releases may evolve the public API.

## Qualification

Before this version is promoted to `main`, the complete STM32H755 hardware campaign must pass with exactly 40 passes, zero failures and exit code zero. The hardware run remains a manual release gate because the NUCLEO fixture is not attached to GitHub-hosted runners.

After promotion, successful `main` CI creates `v0.1.0` from the root `VERSION` file and launches packaging automatically.

See `CHANGELOG.md` for the supported surface and known boundaries.
